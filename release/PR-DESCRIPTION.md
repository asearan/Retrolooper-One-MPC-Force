Adds RetroLooper One for MPC One+ and an explicitly experimental Force port, with separately packaged native integration helpers. Each effect declares its exact helper dependency so current catalog installers add the matching pair to one batch; only one insert effect appears on the device. Unique asset patterns keep the two device editions separate.

The public repository includes GPL-3.0-only source, build/installation instructions, font and upstream notices, 2:1 thumbnails and native-skin preview screenshots. All four portable packages pass the current catalog checker with --catalog, --require-portable, expected IDs and expected repository, with zero warnings. The MPC binaries and both helpers retain their tested production hashes. The Force effect was rebuilt from the curated source with the shared RetroLooper One display name; its audio engine is unchanged and the sanitized Force host suite passes.

MPC One+ 3.10.0.49 hardware testing is recorded in tested.json for effect 0.3.6 and helper 0.2.7. The Force 0.1.0 pair is capped experimental: isolated production-library/helper tests and startup readiness passed, but live Arrange/audio/pad functional checks remain pending. No Gen2 compatibility or automatic native Audio timeline bounce is claimed. The helpers are restricted to their exact validated firmware images and chain their controller hooks.
